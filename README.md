## Experience

### Goldman Sachs — Software Engineering Intern
Worked on the cloud migration and data architecture of a collateral-management platform supporting **$70B+ in assets**. Helped migrate four Java/Spring Boot services, 40+ REST APIs, and three databases to AWS while redesigning transactional and analytical data flows.

### CharityStack — Product Engineer
Worked across CharityStack’s in-person donation product and payment infrastructure for a platform supporting **$50M+ in contributions**. Built mobile donation flows with Stripe Terminal and backend services for asynchronous payment processing.

### An-Nisa Hope Center
Built software supporting nonprofit operations across food pantry services, education, payments, volunteers, reporting, and internal workflows.

### University of Texas at Austin — Research Assistant
Worked on machine learning projects using large datasets, including NLP analysis with DistilBERT and environmental forecasting across multi-year sensor data.

## Projects

### [Helm](https://helmpm.app)
**LLM-Native Project Management**

Built Helm to bring tickets, docs, meetings, code, integrations, and project knowledge into one multi-tenant workspace.

Worked across the backend, indexing and retrieval pipeline, project integrations, and agent workflows. The platform supports multiple organizations and thousands of tickets.

---

### [Amanah](https://github.com/adilW-2005/hack-msa)
**Nonprofit Spend Controls**

Built Amanah to enforce nonprofit spending policies before transactions are approved.

The platform connects grants, budgets, policies, and virtual cards so spending can be checked against merchant, category, balance, approval, and program restrictions in real time.

---

### [UT Student Living](https://github.com/adilW-2005/RoomSync)
**Roommate Management Platform**

Built a cross-platform platform for managing expenses, chores, events, messaging, shared inventory, voting, and other roommate workflows in one place.

The product was designed around reducing the friction of coordinating day-to-day responsibilities between roommates and shared households.

---

### [Food Pantry Platform](https://github.com/adilW-2005/FoodPantry)
**An-Nisa Hope Center**

Built a pantry-management platform supporting operations that serve **500+ people each month**.

The system centralizes client intake, eligibility, visit history, inventory, access controls, and audit logging for day-to-day pantry operations.
